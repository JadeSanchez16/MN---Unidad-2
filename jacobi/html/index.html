Demostración de convergencia

Se verifica el criterio suficiente de dominancia diagonal estricta por filas.

Condición para cada fila i |aii| > Σj ≠ i |aij|
Fila |aii| Desarrollo de Σ |aij| Σ |aij|, j ≠ i Comprobación

Garantía teórica: la dominancia diagonal estricta es una condición suficiente para que el método de Jacobi converja hacia la solución única desde cualquier vector inicial; por tanto, también converge desde x(0) = [0, 0, 0, 0]T.

03

Esquema iterativo

Cada componente nuevo usa exclusivamente valores de la iteración anterior.

x1(k+1) = (15 + 2x2(k) + x3(k)) / 10
x2(k+1) = (18 + x1(k) + 2x4(k)) / 8
x3(k+1) = (25 + 2x1(k) + 3x4(k)) / 12
x4(k+1) = (20 + x2(k) + 2x3(k)) / 9
