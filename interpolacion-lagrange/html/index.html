02

Polinomios base de Lagrange

Para cuatro puntos se construyen cuatro polinomios fundamentales de grado 3.

Fórmula general Lk(x) = ∏i=0, i≠k3 (x - xi) / (xk - xi)

L0(x)

L0(x) = [(x - 4)(x - 8)(x - 12)] / [(2 - 4)(2 - 8)(2 - 12)]

= -(x - 4)(x - 8)(x - 12) / 120

= -x3/120 + x2/5 - 22x/15 + 16/5

L1(x)

L1(x) = [(x - 2)(x - 8)(x - 12)] / [(4 - 2)(4 - 8)(4 - 12)]

= (x - 2)(x - 8)(x - 12) / 64

= x3/64 - 11x2/32 + 17x/8 - 3

L2(x)

L2(x) = [(x - 2)(x - 4)(x - 12)] / [(8 - 2)(8 - 4)(8 - 12)]

= -(x - 2)(x - 4)(x - 12) / 96

= -x3/96 + 3x2/16 - 5x/6 + 1

L3(x)

L3(x) = [(x - 2)(x - 4)(x - 8)] / [(12 - 2)(12 - 4)(12 - 8)]

= (x - 2)(x - 4)(x - 8) / 320

= x3/320 - 7x2/160 + 7x/40 - 1/5
